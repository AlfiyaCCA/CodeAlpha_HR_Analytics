# HR Analytics Dashboard (CodeAlpha Internship - Task 2)

Power BI dashboard analyzing employee attrition, satisfaction, performance and hiring trends.

## Features
- KPI cards: Attrition Rate, Employees Left, Total Employees
- Attrition by Department, Age Group and Job Role
- Average Job Satisfaction and Performance Rating by Department
- Hiring trend with forecast
- Interactive slicers (Department, Gender)

## Key Insights
- Overall attrition rate is 16.12% (237 employees left)
- Sales department has the highest attrition (20.63%)
- Sales Representative role has the highest attrition (39.76%)
- Most exits are in the 25-34 age group (112 employees)

## Tools
Power BI Desktop, DAX
